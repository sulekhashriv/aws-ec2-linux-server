# Important Linux Commands

## System Information

uname -a
cat /etc/os-release
hostname

## Directory Commands

pwd
ls
cd
mkdir

## File Commands

touch
cat
nano
cp
mv
rm

## System Management

sudo dnf update -y
sudo systemctl status httpd
sudo systemctl start httpd
sudo systemctl stop httpd
sudo systemctl restart httpd

## Disk and Memory

df -h
free -m
top

## Network Commands

ip addr
ping google.com
curl http://localhost
